## 4. 加好友专用独立 Session 与决策流程

- [ ] 4.1 网关事件接入：捕获 `request.friend` 事件，分流至专用会话 `peer = "friend_requests"`，不打扰其他私聊
- [ ] 4.2 决策上下文装配：自动提取请求人 QQ、验证理由，并联动 `read_memory` 提取请求人的全局用户画像
- [ ] 4.3 准则注入：装配管理员配置的 `friend_request_policy`（默认兜底：熟识或理由正当可同意，无画像陌生人谨慎）
- [ ] 4.4 阅后即焚生命周期：决策完成后自动释放并销毁临时会话，不遗留脏数据
- [ ] 4.5 契约测试：入站好友请求触发独立 Session、画像与准则正确注入、处理后 Session 正常销毁
