## 2. 核心实施细节

### 2.1 依赖安装与版本核验
执行 `pnpm install` 成功完成锁定，`node_modules/@deepseek-ai/*` 全家桶均实装为 `0.2.1-rc.2`，cordis 实装为 `4.0.5`。

### 2.2 Boot 运行时服务装配 (`src/boot.ts`)
- 0.2.1 已移除 0.1.5 的 `healProfilesModuleFallback` 临时符号；
- 在 0.2.1 中，通过官方 `@deepseek-ai/dsh-app-boot` 的 `createRuntimeResolution({ installAnchor, home: dshHome })` 生成全量依赖解析映射，并在 `boot` 宿主准备回调中挂载 `await hostCtx.plugin(PluginPackages, { resolution })`；
- 该装配使得 Cordis Loader 在沙箱测试目录加载 `@deepseek-ai/*` 插件时通过内置运行时拦截器无缝解析，不再依赖任何物理软链接。

### 2.3 Settings 操作对齐 (`src/server/routes.ts` & `src/config/migrate.ts` & `src/index.ts`)
- 移除 `settings.mutate(ops)` 单参错误调用（在 0.1.5 与 0.2.1 中均非法）；
- 规范使用 `await settings.mutate(SETTINGS_NAMESPACE, ops)`；
- 移除对 0.2.1 中不存在的 `settings.get(ns)` 的强制依赖，优先使用 `settings.describe()` 寻找配置描述项。
