# 开发日志与过程追踪 (devlog)

本目录用于存放开发过程中的过程性文档，包括需求文档、检查清单 (Checklist)、技术探查报告、根因排查记录与阶段交付报告。

---

## 目录结构与规则

### 1. 顶层活跃文档
- 存放当前正在开发、调试或待验收的功能文档。
- 包含：
  - `需求文档-<主题>.md`：功能需求与接口定义
  - `Checklist-<主题>.md`：开发任务拆解与测试跟踪
  - `todo-<主题>.md`：待办项
  - `根因分析-<主题>.md`：排查中或刚复盘的缺陷记录
- 阶段完成后，对应的活跃文档归入 `archive/` 目录。

### 2. 归档目录 (`archive/`)
- 存放已验收交付的历史阶段文档与技术调研沉淀。
- 目录命名为 `archive/<主题>_<YYMMDD>/` 或对应功能包目录。
- 归档内容保留历史事实记录，包括协议抓包采样、升级迁移适配方案与缺陷修复报告。
