## 1. 目标与背景

在 QQ 会话专属预设系统（`qq-session`）实现纯净化隔离后，全局的 Prompt 和预设是静态绑定的。
为提升群聊与私聊的拟人灵动感与拟真体验，系统需具备 **Agent 自修改演进机制**：
1. **群专属人设自演进**：Agent 能够根据不同群聊的氛围、群友偏好自主演变性格（例如：用户要求“以后语气傲娇一点”、“遇到xx关键词要调侃”）；
2. **行为准则自我固化**：在对话中通过用户反馈，自主修订并持久化沉淀群内专属准则；
3. **软硬隔离安全防御**：人设软演进（Soft Soul）与系统权限硬策略（Hard Policy）严格解耦，杜绝越狱提权风险。

---

## 2. 核心架构设计：分层自治模式（Prompt 软演进 + 权限硬策略）

借鉴 Claude Code 体系中的 `CLAUDE.md` / `SOUL.md` 理念，将"**人设与行为准则（Soft Soul）**"与"**系统工具与权限（Hard Policy）**"彻底物理分离：

```
┌────────────────────────────────────────────────────────┐
│ 工具权限硬策略 (Hard Policy)                            │
│ - 由管理员与预设模板严格控制                           │
│ - 工具白名单由系统底层判定，普通群友对话严禁越权开放   │
└──────────────────────────┬─────────────────────────────┘
                           │ 权限物理隔离
                           ▼
┌────────────────────────────────────────────────────────┐
│ 人设与准则软演进 (Soft Soul / Dynamic Instructions)    │
│ - 开放给 Agent 自主修订（或通过管理命令触发）          │
│ - 存放在持久化存储层，热加载注入系统提示词             │
└────────────────────────────────────────────────────────┘
```

### 2.1 存储与作用域设计
- 存储路径：`.dsh/napcat/soul/<peer>.md`（如 `group_123456.md`, `user_1000000001.md`）；
- 会话启动与刷新时，`agent-runner.ts` 自动将对应 peer 的 `soul.md` 注入为 System Prompt 的动态 Context Section；
- 继承与回退机制：当指定 peer 尚无专属 soul 时，回退至全局 `config.persona` 与 `config.behavior`。

### 2.2 Agent 自演进工具设计
为 Agent 注册专属自我演进工具：
- **工具名称**：`update_agent_soul`
- **入参设计**：
  ```ts
  {
    action: 'append_rule' | 'rewrite_persona' | 'get_current',
    content: string, // 待追加或更新的人设准则文本
    reason: string   // 演进理由（记录在审计日志中）
  }
  ```
- **权限与安全栅栏**：
  - 群聊普通对话中，仅允许调用 `append_rule`（追加群规偏好）或通过管理员白名单鉴权后允许 `rewrite_persona`；
  - 严禁通过此工具开放底层宿主工具（如 Shell、文件写入等），工具权限完全不由此工具承载；
  - 工具修改后，立即原子写入目标 peer 的 `soul.md` 文件，并在下一轮对话生效。
