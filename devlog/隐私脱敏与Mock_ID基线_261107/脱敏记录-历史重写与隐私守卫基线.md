## 4. 隐私守卫机制

### 4.1 组成

| 文件 | 作用 |
|---|---|
| `privacy/policy.json` | 可审计策略：允许段、例外值、身份字段名、忽略规则 |
| `scripts/privacy-guard.ts` | 扫描器：识别身份 ID 上下文并校验允许段；报告仅输出掩码 |
| `tests/contract/privacy-guard.test.ts` | 契约测试：单元行为 + 仓库全量扫描必须零违规 |

### 4.2 识别的身份上下文

- 键值上下文：`user_id` / `group_id` / `uin` / `qq` / `bot_qq` / `sender_id` / `self_id` / `target_id` / `from_user` / 驼峰变体等；
- 会话标识：`user_<id>`、`group_<id>`、`qq-user-<id>`、`qq-group-<id>`；
- CQ 码：`[CQ:at,qq=<id>]`；
- 日志形态：`[昵称(<id>)]`；
- 文本形态：`QQ: <id>`。

显式排除 `message_id` / `msg_id` / `real_id` / `reply_to` / `time` / `message_seq` / `seq` 等非身份数字，避免误伤。

### 4.3 运行方式

```powershell
pnpm check:privacy   # 手动运行
pnpm test            # build + vitest run（含隐私契约测试）
pnpm test:quick      # vitest run（含隐私契约测试）
```

### 4.4 测试夹具安全

隐私契约测试自身需要“疑似真实 ID”作为夹具，全部通过字符串拼接构造（如 `['16','17','30','72','95'].join('')`），确保测试文件本身不会成为新的隐私泄漏源，也不会被仓库全量扫描误判。
