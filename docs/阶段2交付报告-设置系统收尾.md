## 2. 核心技术实施说明

### 2.1 易失性标记 `.volatile()` 语义对齐（A7）
- Cordis Plugin Loader 在 `_commitVolatile` 时仅对包含 `meta.volatile: true` 的字段触发 `loader/volatile-update` 动态热更新；未标记的字段修改会导致整个插件卸载重载；
- 机器人的核心身份标识 `bot_qq` 修改涉及 self-id 与会话锚定重算，属于结构性变更，因此**不添加** `.volatile()`；
- 其余 24 个运行时参数（如 `ws_port`, `ws_token`, `persona`, `behavior`, `proactive_*`, `memory_*`, `review_*` 等）均已实现内存级热更新或重连，全部标记为 `.volatile()`。

### 2.2 `memory_budget_chars` 废弃键彻底清零（A8）
- 历史遗留的 `memory_budget_chars` 曾导致生产代码多处双重/三重兜底并在迁移时被整包写回 settings，违反 0.2.1 规范；
- 现已将其彻底移除：
  - `src/types/index.ts` 的 `BridgePluginConfig` 与 `src/memory/types.ts` 的 `MemoryPluginConfig` 移除该属性；
  - `src/client/card.tsx` 默认值与模板取值移除该属性，仅保留 `group_memory_budget_chars` 与 `private_memory_budget_chars`；
  - `src/config/migrate.ts` 仅在探测旧版 YAML 时读取一次并重命名映射为 `group_memory_budget_chars`，迁移后执行 `delete (legacyValues as any).memory_budget_chars`，绝不写回新配置文件；
  - `src/index.ts` 移除针对该旧键的读取兜底。

### 2.3 0.2.1 插件元数据与 Locale 子路径规范（A15）
- DSH 0.2.1 `readPluginMeta` 解析子路径 `<specifier>/locale/en.json` 与 `<specifier>/locale/zh.json` 获取插件标题与描述；
- 项目根目录下规范创建 `locale/en.json` 与 `locale/zh.json`，并在 `package.json` 的 `exports` 中暴露 `./locale/*`，同时加入 `files` 数组；
- 0.2.1 已取消 `<specifier>/icon` 的子路径导出要求，元数据直接支持读取 `package.json.icon`。

### 2.4 Boot Overlay 伪配置绑定移除（A12）
- 0.2.1 中 settings 服务基于 active profile 与 Profile Patch 运作，不再消费 0.1.5 的 `settings: { path: configPath, watch: false }` 覆盖行；
- `src/boot.ts` 已移除该多余覆盖层。
