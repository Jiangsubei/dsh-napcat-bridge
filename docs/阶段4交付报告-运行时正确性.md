## 2. 关键代码改动详情

### 2.1 审批与提问（A3-A5, B4, D4）
- `src/approval/responder.ts`：
  - 超时时返回 `rejected`（fail-closed 语义），杜绝挂起泄漏；
  - `signal.addEventListener('abort')` 时返回 `cancelled`；
  - 同一 peer 发起新审批时，若存在前序未完成请求，前序请求以 `cancelled` 结果决议收敛；
  - 群聊审批校验 `admins` 白名单配置：非管理员发送 `y` 不予放行并警告；
  - 完整透传 `callId` 契约。

### 2.2 出站串轮、TTL 与清理（A23/B3, B6, B7）
- `src/outbound/stream.ts`：
  - 在 `turn/start` 事件中认领该 peer 所有的 pendingContexts，防止多回合并发交错导致的串轮与漏发；
  - 增加 5 分钟 TTL 扫描清理过期 pendingContexts；
  - 增加 `dispose()` 方法，在插件卸载时清理定时器与上下文。
- `src/outbound/queue.ts`：
  - `PerPeerSerialSender` 在执行完任务且队列为空时，自动从 `this.chains` Map 中删除 peer 键，杜绝长期运行导致的无界内存泄漏。

### 2.3 网关与安全（B1, B2, B5）
- `src/gateway/server.ts`：
  - 在 WebSocket 入站消息处理入口包装 `.catch(err => logger.error(...))`，杜绝异步未捕获异常崩溃服务。
- `src/storage/media.ts`：
  - 落盘路径与缓存路径增加 `path.resolve` 与目标目录前缀校验，杜绝路径穿越；
  - `file://` 路径改用 `new URL(url)` 和 `fileURLToPath` 进行跨平台规范化解析。
- `src/index.ts`：
  - `shouldWakeup` 传递 `bot_nickname: (currentConfig() as any).bot_nickname || (currentConfig().aliases?.[0] ?? undefined)`，让群聊别名与戳一戳唤醒在生产环境真实生效。

### 2.4 工具与命令（B14, B15, B16）
- `src/tools/index.ts`：
  - 工具执行失败时显式 `throw`，确保 Agent Runtime 准确获知工具失败并触发规划调整；
  - `wait_for_user_messages` 增加超时判定；
  - 移除对内部函数 `saveSelection` 的猴补丁修改与空 catch。
- `src/commands/index.ts`：
  - 命令解析与执行错误向外如实抛出或反馈，不再静默吞并。

### 2.5 记忆系统（A16-A18, B8-B13, D2）
- `src/utils/atomic-write.ts`：
  - 新增 `atomicWriteFileSync`，写入随机临时文件后执行 `fs.renameSync`，并包含 Windows 跨卷/独占回退，保障掉电与并发安全。
- `src/memory/storage.ts`：
  - 新增 `updateSessionMemory` 与 `updateUserProfile` CAS 原子互斥更新方法；
  - 同步写入方法全面接入 `atomicWriteFileSync`；
  - `getPromptSnapshotSync` 实施严格预算硬上限与预估拦截。
- `src/memory/tools.ts`：
  - 移除对 `anyCtx.userId/user_id/agent.userId` 的无端猜测，改用 `getCurrentSpeaker(peer)` 真实上下文；
  - 分流私聊（1500 字符）与群聊（2200 字符）预算；
  - `edit_memory` 接入 storage CAS 原子互斥更新。
- `src/memory/review.ts`：
  - 对齐 DSH 0.2.1 官方机制：在 `setup: (agentCtx) => { agentCtx.tools.restrict({ allow: [...] }) }` 中限制工具白名单；
  - `agent.cancel({ kind: 'parent' })` 修复必填原因契约；
  - 对齐官方服务名 `sessionProjections` 并剔除 `spillStore`；
  - 接入动态配置 getter 支持热更新。
- `src/index.ts`：
  - 维护 `currentSpeakers: Map<string, string>` 记录发言人并在消息到来时更新，传递给 memoryService。
