# 任务包：新增「仅回复文本内容」开关（纯文本模型专用）

> **项目**: dsh-napcat-bridge  
> **日期**: 2026-09-06  
> **优先级**: P2  
> **一句话**: 新增一个只作用于**主动唤醒/主动回复**入站判断的布尔开关。开启后（部署纯文本模型时），只有收到**纯文本消息**才可能触发主动回复；含视频/图片/表情包/文件等任一**多模态段**的消息一律不主动回复。

---

## 1. 背景与边界（务必遵守）

- 开关**只影响主动唤醒的入站判断**，与**任何其他东西无关**：
  - ❌ 不影响出站消息渲染（stripMarkdown / at / reply / send_file）
  - ❌ 不影响后台回顾（memory review）
  - ❌ 不影响用户手动 @ / 待回复的定向消息
- 一句话语义：**开启后，非纯文本消息不进主动唤醒决策**。
- 名称：UI 文案用「**仅回复文本内容**」（注意是「仅」不是「只」）。
- 位置：**主动回复大类下的一个小开关**（同 `proactive_random_enabled` 等并排）。

## 2. 设计定稿

### 2.1 配置项（src/config/schema.ts + src/types/index.ts）

```ts
proactive_only_text: z.boolean().default(false).description(
  '仅回复文本内容（纯文本模型专用）：开启后仅对纯文本消息触发主动回复，视频/图片/表情包等多模态消息一律不主动回复'
)
```

- 默认 `false`（不改变现有行为）
- types 侧 `BridgePluginConfig` 加可选字段 `proactive_only_text?: boolean`
- 常量 `DEFAULT_PROACTIVE_ONLY_TEXT_ENABLED = false`（constants）

### 2.2 唤醒闸口（src/gateway/wakeup.ts `isExcludedFromProactive`）

- 该函数是主动唤醒判断消息是否排除的唯一入口（随机唤醒 + 冷场冒泡等路径都经它）。
- 新增逻辑（置于函数最前，早退）：

```ts
// 仅回复文本内容模式：任何含非文本段的消息一律排除（不主动回复）
if (onlyText) {
  const hasNonTextSegment = segments.some((seg) => seg && !['text', 'at', 'reply'].includes(seg.type));
  if (hasNonTextSegment) return true;
}
```

- `onlyText` 由调用方传入（从 config 读取 `proactive_only_text`）。
- 判据：段类型属于 `text`/`at`/`reply` 算「文本」；其余（`image`/`video`/`record`/`face`/`mface`/`marketface`/`file`/`json`/`xml`/…含图片+文本混合）均算「非文本 → 排除」。
- 兜底 `raw_message` 正则分支：当 segments 为空走 raw 时，开启模式额外检查 `[CQ:image`/`[CQ:face`/`[CQ:mface`/`[CQ:file`/`[CQ:video`/`[CQ:record` 等 CQ 多模态码，命中即排除。

### 2.3 调用方接线（实现时核实）

- 找出 `isExcludedFromProactive` 的所有调用点（随机概率唤醒、潜水超时唤醒等）。
- 确保 config `proactive_only_text` 从当前配置注入到每次判断（不要在模块加载时固化）。

### 2.4 UI（src/client/card.tsx）

- 在主动回复分区（`proactive_*` 开关组）内新增一个开关：
  - id 形如 `napcat-proactive-only-text`
  - label = `仅回复文本内容 (proactive_only_text)`
  - hint = `开启后（纯文本模型部署）：只有纯文本消息会触发主动回复；视频/图片/表情包等多模态消息一律不主动回复`
  - checked 默认 `false`
  - 依赖 `proactive_reply_enabled` 总开关（总开关关时 disabled）
  - 参与 draft 存续、isOverridden、reset、onChange 等现有机制
- card.tsx 顶部 `defaults` 加 `proactive_only_text: false`
- `src/client/model.ts`（如有字段清单）同步
